Создавайте изолированные витрины, назначайте тарифы и включайте модули. Console принимает только ссылки env:ИМЯ_ПЕРЕМЕННОЙ, а не реальные токены и ключи.

Тестовый магазин: порядок

  1. Создайте отдельного Telegram test-бота и выберите тестового владельца.
  2. Создайте уникальный черновик с test-* поддоменом.
  3. Задайте переменные окружения на сервере, затем сохраните только ссылки env:... на Bot Token и Webhook Secret.
  4. Подготовьте runtime, запустите worker, откройте canonical /setup, подтвердите владельца и активируйте магазин.
  5. YooKassa и custom domain можно добавить позже; после изменения secret reference перезапустите worker.
